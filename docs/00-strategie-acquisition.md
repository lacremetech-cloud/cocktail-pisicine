# Cocktail Piscine (Occi Piscines 34) — Fondation stratégique acquisition

> Socle de travail. Alimente : funnels (quiz + catalogue), créas ads, scripts de setting, tracking.
> Client : Occi Piscines / Cocktail Piscine 34 — Jacou (34). Coques polyester. Panier moyen 17 000 € HT.
> Deal : Rayyân growth partner, 10 % du devis HT signé. **Rayyân avance le budget ads.**

---

## 1. Positionnement offre (côté prospect)

Ce qu'on VEND au prospect, ce n'est pas "une piscine", c'est :
**« La piscine coque française, posée clé en main près de chez vous, sans mauvaise surprise, par une équipe locale notée 5/5. »**

Piliers de réassurance (à répéter partout) :
- **Coque polyester = pose rapide** (quelques jours vs. plusieurs semaines pour le béton)
- **Fabrication française** (7 usines, 40 ans) + **garantie décennale**
- **Équipe locale** (Jacou, Hérault/Gard) — visages, avis 5/5, FPP
- **Prix maîtrisé** : "meilleur rapport qualité-prix", à partir de ~15-17 k€

---

## 2. Avatar principal — "La famille qui veut son été à la maison"

| Dimension | Détail |
|---|---|
| Profil | Couple 35-55 ans, propriétaire d'une maison avec jardin, 1+ enfant < 15 ans, CSP+ ou moyenne sup. |
| Zone | Périphérie Montpellier / Nîmes (Hérault + Gard) — pavillon avec terrain |
| Motivation n°1 | **Convivialité / bien-être en famille** — "profiter de l'été ensemble à la maison" |
| Motivation n°2 | **Valoriser le patrimoine** — la piscine augmente la valeur de la maison |
| Motivation n°3 | Confort / plus besoin de partir, chaleur locale l'été |
| Déclencheur | Été qui arrive, enfants qui grandissent, emménagement récent, prime/héritage |

### Objections à désamorcer (dans ads + funnel + setting)
1. **"C'est trop cher"** → coque = meilleur rapport qualité-prix + financement possible + à partir de X€
2. **"Les travaux, la galère, les délais"** → coque posée en quelques jours, clé en main
3. **"Entretien compliqué"** → coque = surface lisse, moins d'entretien
4. **"Est-ce que ça tient dans mon terrain ?"** → étude gratuite + 38 modèles dont mini-piscines
5. **"Je me méfie des piscinistes"** → équipe locale, avis 5/5, FPP, garantie décennale

## 4. Funnels (A/B test)

### Funnel A — Quiz-estimateur (priorité qualité)
1. Type de piscine imaginée (visuels : fond plat / fond incliné / mini)
2. Surface de terrain + accès engin
3. Délai projet (< 3 mois / cette année / je me renseigne)
4. Budget envisagé (fourchettes autour de 17 k€)
5. Propriétaire ? + Code postal (filtre Hérault/Gard)
6. Coordonnées → **"Votre estimation personnalisée + le catalogue 38 modèles"**
→ Merci + promesse de rappel < 24 h.

### Funnel B — Téléchargement catalogue (priorité volume)
- Landing simple : promesse ("Le catalogue des 38 modèles + les prix indicatifs")
- Form court (nom, email, tel, code postal) → PDF envoyé + rappel.

**Règle d'or lead gen** : moins de champs = plus de conversion ; rappel < 24 h obligatoire.
On compare CPL, taux de RDV, taux de close entre A et B → on garde le gagnant.

---

## 5. Setting (le levier P&L de Rayyân)

Comme Rayyân avance les ads, la vitesse + qualité de setting = rentabilité.
- **Rappel < 1 h** en horaire ouvré (idéalement < 5 min).
- Objectif de l'appel : qualifier (budget réel, terrain, délai, propriétaire) + **caler une visite/RDV avec l'équipe Occi**.
- Grille de qualification : propriétaire ✓ / terrain compatible ✓ / budget ≥ ~12 k€ ✓ / délai < 12 mois ✓.
- Transmettre à Occi uniquement les leads chauds → protège la relation client + le close rate.

---

## 6. Tracking & KPIs (à instrumenter dès J1)

CPL · taux lead→RDV · taux RDV→devis · taux devis→signature · **CAC** · commission générée · **net après ads**.
Break-even test prudent ≈ **1 vente / 1 500 € d'ads**. Kill les angles sous-performants vite.
